ShortX 弹出类 Action 深色模式交接文档

用途：给后续 AI / 工程师继续接手本需求。内容覆盖需求目标、动作范围、当前已实现状态、未完成项、关键文件和后续 tasking。

需求摘要

给“会弹出页面 / 浮层 / 对话框 / 独立页面”的 ShortX 自渲染动作增加主题模式选项，并在运行时根据动作自身配置，以 跟随系统 / 浅色 / 深色 三态来展示 UI。

用户确认的范围

只做 ShortX 自己控制渲染的 UI。系统面板、最近任务、电源菜单、外部 App 页面不要求强制套主题。

1. 本次需求范围

纳入范围

  • ShortX 对话框
  • ShortX Compose 浮层 / Overlay
  • ShortX 侧边栏 / Action Sidebar
  • ShortX 剪贴板浮层 / 画板 / 选区 / UniversalCopy / ViewIdViewer
  • ShortX 自己的 Activity：DisplayImage、BiometricVerify

不纳入范围

  • 系统通知面板：ExpandNotification
  • 系统最近任务：ShowRecentApps
  • 系统全局操作菜单：ShowGlobalActionsMenu
  • 外部 App 页面：LaunchApp、StartActivity*、AppShortcut

3. Tasking 拆分

  1. 定义共享主题模式枚举与解析逻辑
  2. 给目标 action proto 增加主题字段
  3. 给 Kotlin action model 增加字段并打通 proto 映射
  4. 让共享运行时主题入口支持 UiThemeMode
  5. 对话框类动作通过 DialogUiStyleSettings.themeMode 生效
  6. Compose 浮层类动作通过 ShortXServiceUITheme(themeMode) 生效
  7. Activity 类动作通过局部 night mode 生效
  8. 给已有 selector 的动作增加主题模式选择 UI
  9. 给原本无配置页的动作补一个轻量 selector，仅配置主题模式
  10. 编译并验证跨模块联动，尤其是 services-ui/jar/classes.jar 依赖链

注意：services 模块依赖的是仓库中的 services-ui/jar/classes.jar，不是直接依赖 :services-ui 源码模块。因此每次改动 services-ui 以后，必须重新生成并同步这个 jar。
