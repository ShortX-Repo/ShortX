# external/codeditor

## Role

`external/codeditor` packages a code editor surface used by ShortX when users edit script-like content such as expressions or command bodies.

## Module Type

- Android library

## Ownership

- Vendored support module

## Why It Matters

It supports rule and script authoring UX, especially where MVEL, code-like text, or structured editing is exposed in the UI.

## Reading Outcome

Read this module only when you need to change the embedded editor behavior.
