# external/dex-maker

## Role

`external/dex-maker` provides runtime DEX and bytecode generation support.

## Module Type

- Java library

## Ownership

- Vendored support module

## Why It Matters

This module is important for understanding advanced dynamic behavior, especially in Xposed-related paths where generated classes or dynamic hooking support may be needed.

## Reading Outcome

Read this when a hook or runtime path depends on generated bytecode rather than static classes.
